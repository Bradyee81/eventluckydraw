**What's new**

- **Fewer antivirus false alarms (Norton and others).** Lucky Draw no longer runs PowerShell in the background or reads saved WiFi passwords from Windows. Antivirus software such as Norton treated that combination as suspicious and could quarantine the app when you pressed Refresh in Buzzer setup.
- **Type the WiFi password in Buzzer setup.** Because the app no longer reads it from Windows, enter the venue WiFi password in the new box before pressing **Connect**. It's sent only to the buzzer over USB and isn't saved.
- The firewall and USB driver buttons now use the normal Windows admin prompt directly.

If Norton quarantined an earlier version, restore it (or reinstall) after updating.

**New install:** download the file ending in `_x64-setup.exe` below and run it. Already have Lucky Draw 0.2.0 or later? Open it and press **Update now**.
