**What's new**

- **One buzzer press per winner in Manual Draw.** Once the operator has typed the announced number, a single buzzer press logs the winner and goes straight on to rolling for the next one. A message at the top confirms it, e.g. "✓ Logged 123456 — rolling for next winner", and the winner appears in Recent Draws as usual.
  - Before any number is typed, a press starts the reels rolling.
  - A press while the number is only half typed does nothing, so it can't disturb the entry.
  - A number that isn't on the participant list isn't logged, and the reels don't roll on (unless Fail-safe is on).
  - Using the on-screen **Confirm** button instead still works as before: the winner stays on screen, and the next buzzer press starts the next draw.

**New install:** download the file ending in `_x64-setup.exe` below and run it. Already have Lucky Draw 0.2.0 or later? Open it and press **Update now**.
