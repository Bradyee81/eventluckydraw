**What's new**

- **Choose which screen to present on.** Present now sits at the bottom of the side menu, with a screen picker above it (e.g. "Display 2 — 1920×1080"). The Output window opens fullscreen on the screen you pick, and the app remembers your choice. When the menu is collapsed, a small ▶ button still presents.
- **Exit Present closes the Output window.** The Output window now only appears while you're presenting, and no longer opens when the app starts.

**New install:** download the file ending in `_x64-setup.exe` below and run it. Already have Lucky Draw 0.2.0 or later? Open it and press **Update now**.
