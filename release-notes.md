**What's new**

- **The buzzer now logs the winner in Manual Draw.** Before, every buzzer press just rolled the reels again, even after the number was typed, so the winner wasn't logged. Now it's two presses per winner:
  1. **Press:** the reels roll. Type the announced number.
  2. **Press:** the winner is logged, just like pressing Confirm.

  The next press clears the screen and rolls for the next winner. A press while the number is only half typed does nothing, so it can't disturb the entry. Numbers that aren't on the participant list still can't be logged (unless Fail-safe is on).

**New install:** download the file ending in `_x64-setup.exe` below and run it. Already have Lucky Draw 0.2.0 or later? Open it and press **Update now**.
