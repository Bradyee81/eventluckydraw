**What's new**

- **Install the buzzer's USB driver from the app.** Setup → Config → Buzzer setup now shows whether the buzzer's USB driver (CP210x) is installed. If it's missing, for example because the installer's admin prompt was declined, press **Install USB driver** and approve the prompt. No need to reinstall Lucky Draw.

**New install:** download the file ending in `_x64-setup.exe` below and run it. Already have Lucky Draw 0.2.0 or later? Open it and press **Update now**.
