**What's new**

- **Different slot counts per draw.** Set each draw's number of digit slots under Setup → Draws (e.g. Lucky Draw = 4, Grand Lucky Draw = 7). Choosing a draw switches the Output window automatically.
- **A separate ticket list for each draw.** When importing participants, choose which draw the list is for. Each draw only matches and picks its own tickets, plus any marked "All draws".
- The Section button on Draw and Auto Draw now offers your draws as one-click picks.

**New install:** download the file ending in `_x64-setup.exe` below and run it. Already have Lucky Draw 0.2.0 or later? Open it and press **Update now**.
