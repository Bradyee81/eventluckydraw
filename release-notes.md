**What's new**

- **Buzzer setup is more reliable at new venues.** When a buzzer still remembered a WiFi network that wasn't available, it took too long to start up, and Connect gave up with "Buzzer didn't respond in time". The app now waits for the buzzer to finish starting up before sending the WiFi details. Connecting can take up to 30 seconds.
- **The right USB port is picked automatically.** The buzzer's port is listed first, and Bluetooth ports (which can't be a buzzer) are no longer shown.
- **Clearer error messages.** If Connect fails, the message now says whether the buzzer didn't answer at all (wrong port, or no firmware on the buzzer), or got the details but couldn't join the WiFi (wrong password, or a 5 GHz-only router).

**New install:** download the file ending in `_x64-setup.exe` below and run it. Already have Lucky Draw 0.2.0 or later? Open it and press **Update now**.
